Argus Terminal: a Bloomberg-style market terminal, built as a local simulation (educational, not affiliated with Bloomberg). One Node.js process with node:sqlite, a price-time priority (FIFO) matching engine on a TypedArray slab order book, Canvas 2D candlestick and depth charts, a WebSocket tape, and a read-only SQL console. All market data is simulated. One runtime dependency (ws), no build step. Five seeded vulnerabilities (SQL injection, SQL console writes, webhook SSRF, restricted-account access, unbounded orders/payloads) fixed and regression-tested; 5 test suites, 51 checks passing.
