# ARGUS TERMINAL — Launch Video Plan (`brag-plan.md`)

## 1. Product Inspection Summary
- **What is it?** Argus Terminal is an educational, local-only market-terminal simulation with a Bloomberg-style UI (not affiliated with Bloomberg). It runs as a single Node.js process with native `node:sqlite` (WAL mode), an in-memory price-time priority (FIFO) matching engine, a TypedArray slab order book, and HTML5 Canvas 2D charts. All market data is simulated.
- **Who is it for, and what does it do for them?** Developers and students who want to see how an order book, matching engine, WebSocket market feed, and SQL-backed blotter fit together, using six simulated instruments (`BTC-USD`, `ETH-USD`, `SOL-USD`, `NVDA-EQ`, `XAU-USD`, `IDR-USD`).
- **What sets it apart?** No build step, one runtime dependency (`ws`), a read-only SQL console over the live SQLite database, and five seeded vulnerabilities that were fixed and covered by regression tests:
  1. Parameterized order search (SQL injection fix)
  2. Read-only SQL console guard (single `SELECT` only; `accounts`/`api_secret` blocked)
  3. Webhook URL egress filter (blocks loopback/private/link-local targets — SSRF)
  4. API key required for the RESTRICTED account (`ACC-VAULT-99`)
  5. 5x buying-power cap per order + 64KB request body limit
- **Test status:** 5 test suites, 51 checks, all passing — e2e (13), security controls (5), devtools audit (8), wave2 quant (12), wave3 derivatives/FIX (13).
- **Headline:** `"A BLOOMBERG-STYLE TERMINAL, BUILT AS A LOCAL SIMULATION."` → `"ARGUS RUNS LOCALLY."`
- **Visual Hook:** Obsidian `#06080c` screen, amber `#ff9e00` `<GO>` command bar typing `BTC-USD <GO>` on beat, cutting to the full 5-pane terminal at 1920×1080.
- **Tone:** `cinematic` + `polished`, dark-synth D-minor pulse at 120 BPM, beat-locked hard cuts. No price comparisons with other products, no latency or benchmark numbers.
- **Share Caption:** See `share-copy.txt`.

## 3. Audio & Beat Grid Architecture
- **Duration:** `18.0s` (`540 frames` @ `30 fps`)
- **Resolution:** `1920×1080` (16:9 Landscape Full HD)
- **Tempo:** `120 BPM`
  - `1 Beat` = `0.50s` (`15 frames`)
  - `1 Bar (4 Beats)` = `2.00s` (`60 frames`)
  - Total = `36 Beats` (`9 Bars`)
- **Soundtrack Design (`work/soundtrack.wav`, generated by `work/generate_audio.py`):**
  - **Key:** D Minor (`Dm9 -> Bbmaj7 -> Gm9 -> A7sus4`) warm analog-style synth pad.
  - **Sub-Bass:** 55Hz–73.4Hz sub-bass pulse on every quarter-note beat.
  - **Percussion Groove:** Stereo 16th-note closed hi-hats + rim/snare on beats 2 and 4.
  - **Foley & UI Synths:**
    - `t = 0.0s` (Beat 0): Opening chime on Hook Part A.
    - `t = 1.5s` (Beat 3): Impact chime on cut to `"ARGUS RUNS LOCALLY."`
    - `t = 1.82s–2.95s`: Key clicks as `BTC-USD <GO>` types into the command bar, then a `<GO>` confirmation chord at `t = 3.1s`.
    - `t = 3.5s` (Beat 7): Chord swell as the 5-pane workspace reveals.
    - `t = 8.5s` (Beat 17): Scene 3 cut chime.
    - `t = 10.0s` (Beat 20): Dual-tone fill chime (`A5 -> D6`) when the simulated `BUY 2.50 BTC-USD @ MARKET` fills.
    - `t = 11.25s`: Chime on the security panel.
    - `t = 13.5s` (Beat 27): Finale chord for Scene 4.
